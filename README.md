## ClipFeed (`tiktok.html`)

Video-App im TikTok-Stil in einer einzigen HTML-Datei. Die Beispielclips liegen im Ordner `videos/`. Deshalb muss `tiktok.html` neben diesem Ordner liegen, oder du rufst die Seite über GitHub Pages auf.

- Endlos-Feed mit Einrasten beim Wischen. Tippen schaltet den Ton ein, danach Pause/Play. Doppeltipp = Like, gedrückt halten = Menü.
- Creator-Profile, Entdecken-Seite mit Suche und Trend-Hashtags, eigenes Profil (Videos / Gespeichert / Gefällt mir)
- Kommentare mit Antworten, Teilen (WhatsApp, Telegram, X, Text kopieren), Wiedergabetempo, Auto-Weiter
- Likes, Kommentare und Follows liegen im LocalStorage, hochgeladene Videos in der IndexedDB des Browsers. Beides gilt nur für das jeweilige Gerät.
