## ClipFeed (`tiktok.html`)

Eigenständige TikTok-artige Web-App in einer einzigen Datei – einfach `tiktok.html` im Browser öffnen.
Likes, Kommentare, Follows und Profil liegen im LocalStorage, hochgeladene Videos in der IndexedDB des Browsers (nur auf dem jeweiligen Gerät).
